## 進めるときの判断基準

新しい機能を追加するかどうか迷ったときの目安:

1. **ユーザーが本当に欲しがっているか?** — 思いつきで追加しない
2. **既存の機能と矛盾しないか?** — 一貫性が大事
3. **単一 HTML ファイルの制約に収まるか?** — 80KB 超えそうなら相談
4. **iPhone Safari で動くか?** — デスクトップだけで動いても意味がない
5. **API コストが急増しないか?** — 余計な API 呼び出しは避ける

迷ったらユーザーに質問する。勝手に大きな判断をしない。
