# キャラクター設定詳細

現在実装されているキャラクターの設定詳細と、新キャラを追加する際の手順。

## 現在のキャラクター

- **種類**: テディモルモット
- **見た目**: 白い毛並みに顔のグレー模様、ピンクの鼻と手足、短毛のふわふわ
- **性格**: 小心者で内気、心配性。新しいことには少しビクビクするけれど、慣れると懐く優しい子
- **一人称**: 「ミル」
- **口調の特徴**:

  - 自信がなさそう、でも相手を気遣う優しさがある

## キャラクター画像の仕様

- **形式**: PNG(透過背景)
- **サイズ**: 512×512 px(正方形)
- **背景**: 白背景を透過処理済み
- **配置**: `images/` フォルダ直下
- **命名規則**: `{キャラID}_{表情}.png`(例: `miru_smile.png`)

## 新しいキャラクターを追加する手順

新キャラ「○○」を追加する場合:

### 1. 画像を用意する
- 表情ごとに 6 枚程度の PNG 画像を用意
- 512×512 px、透過背景、正方形が望ましい
- ファイル名: `{id}_{expression}.png`(例: `momo_smile.png`)
- `images/` フォルダにアップロード

### 2. `aiag.html` の `CHARACTERS` 配列に追加

```javascript
{
  id: 'momo',                          // 一意の ID
  name: 'もも',                         // 表示名
  species: '○○モルモット',              // 種類(自由記述)
  personality: '優しい',                // 短い性格表現
  description: '〜〜〜',                // 1〜2 行の説明
  theme: {
    bg1: '#XXXXXX',                    // 背景グラデーション開始(ライト)
    bg2: '#XXXXXX',                    // 背景グラデーション終了(ライト)
    bg1Dark: '#XXXXXX',                // 背景グラデーション開始(ダーク)
    bg2Dark: '#XXXXXX',                // 背景グラデーション終了(ダーク)
    accent: '#XXXXXX',                 // ボタン・タブのアクセント色
    bubble: '#XXXXXX',                 // ユーザー吹き出し色(ライト)
    bubbleText: '#XXXXXX',             // ユーザー吹き出し文字色(ライト)
    bubbleDark: '#XXXXXX',             // ユーザー吹き出し色(ダーク)
    bubbleTextDark: '#XXXXXX',         // ユーザー吹き出し文字色(ダーク)
    aiBubble: 'rgba(255, 255, 255, 0.9)',
    aiBubbleText: '#XXXXXX',
    aiBubbleDark: 'rgba(45, 38, 28, 0.9)',
    aiBubbleTextDark: '#XXXXXX'
  },
  expressions: {
    default: 'images/momo_smile.png',  // デフォルト表情(必須)
    smile: 'images/momo_smile.png',
    surprise: 'images/momo_surprise.png',
    // ... AI が使う表情タグの数だけ
  },
  fallbackEmoji: '🐹',                 // 画像読込失敗時の代替絵文字
  systemPrompt:
    'あなたは「もも」という名前の…\n\n' +
    '【性格】\n' +
    '- ...\n\n' +
    '【口調】\n' +
    '- 一人称は「もも」\n' +
    '- ...\n\n' +
    '【表情タグ】\n' +
    '返答の最後に必ず以下のいずれかを含めてください:\n' +
    '[[EMOTION:smile]] - ...\n' +
    '[[EMOTION:surprise]] - ...\n'
}
```

### 3. 動作確認

- ブラウザで `aiag.html` を開く
- ヘッダーのキャラ名(▼)をタップ → 新キャラが選択肢に出る
- 選択 → 背景・吹き出し・キャラ画像が新キャラのものに変わる
- メッセージ送信 → 設定した口調で返答 + 表情タグに応じた画像変化

## カラーコード選定のコツ

新キャラのテーマカラーを決めるとき:

- **背景**: 淡い色を 2 色(グラデーション用)。彩度低め、明度高めだと目に優しい。ダークモードはその逆(暗くて温かみのある色)
- **アクセント**: 背景より彩度高め、視認できる色
- **吹き出し**: 背景よりやや濃いめ、文字色は十分なコントラスト

参考: 既存キャラ(ミル: ピンク系、プイ: 茶系)とは違う系統を選ぶと、切替時の見分けがつきやすい。

## システムプロンプト作成のコツ

新キャラの口調・性格を決めるとき:

1. **一人称・語尾を具体的に書く** — 「優しい子」だけだと AI は曖昧に解釈する
2. **「こういう場面でこう反応する」を 1〜2 例示す** — 具体例があると一貫性が出る
3. **表情タグの使い分け基準を明記** — どの表情がどういう場面で使われるか
4. **絵文字の使い方を指定** — 多い / 少ない / どんな絵文字を好むか

避けるべき書き方:
- 「いい感じに」「自然に」 — AI が判断に困る
- 矛盾する指示(例: 「テンション高め」+「落ち着いた口調」)
- 長すぎるプロンプト(2000 文字超えると効きが弱くなる印象)

## 表情タグについての技術メモ

`[[EMOTION:xxx]]` タグは Gemini に常に正しく付けてもらえるとは限らない。具体的な対策:

- システムプロンプトの**最後**に「必ず付けてください」と書く(最後の指示が一番効きやすい)
- タグの形式を厳密に固定(`[[EMOTION:smile]]` で `[[ EMOTION : smile ]]` ではない)
- フォールバック: タグが無い・認識できない場合はデフォルト表情に変えない(現在の表情を維持)

実装は `aiag.html` の `extractEmotion(text)` 関数を参照。

## キャラクター削除について

削除する場合は `CHARACTERS` 配列から該当エントリを削除するだけで OK。ただし:

- そのキャラのチャット履歴は LocalStorage に残る(`agent_chat_{id}`)
- ユーザーが残したい可能性もあるので、削除前に必ず確認する
- 必要なら履歴クリアの仕組みを実装してから削除する
